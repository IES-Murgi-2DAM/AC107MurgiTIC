# AC107 - Versión Profesor

## Identificación de elementos

- MainActivity: Es la actividad principal de la aplicación, donde se muestra la interfaz de usuario y se manejan las interacciones del usuario.
- SensorScreen: Es el componente que muestra el contenido de la pantalla, incluyendo la medición, el botón y el indicador de lectura
- LoadingIndicator: Es un componente que muestra un indicador de carga mientras se espera la respuesta del sensor.
- AndroidManifest.xml: Está situado en la carpeta `app/src/main/` y contiene información sobre la aplicación, como el nombre del paquete, las actividades y los permisos necesarios.
- build.gradle: Está situado en la carpeta `app/` y contiene información sobre las dependencias y configuraciones del proyecto.
